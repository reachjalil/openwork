# Prompt — OpenWork Interview Prep

Use this prompt with an agent that has loaded `openwork-skill`.

```text
I have an interview to join Different AI's OpenWork as a contributor. Use openwork-skill to brief me.

Cover:
1. What OpenWork is and its product philosophy.
2. The repo structure and tech stack.
3. The runtime architecture: desktop, server, orchestrator, router, Den cloud.
4. Where the project appears to be moving.
5. The main issue/risk clusters.
6. Where someone with my background can be useful.
7. A first contribution proposal I can discuss.
8. Questions I should ask maintainers.

Separate current verified repo state from roadmap/open-PR inference. Keep the answer interview-practical, not just descriptive.
```

Optional personalization fields:

```text
My strengths: <frontend/backend/desktop/cloud/docs/security/integrations/evals>
My available environment: <mac/windows/linux/cloud only>
My goal: <first PR / core contributor / paid contributor / design partner>
```

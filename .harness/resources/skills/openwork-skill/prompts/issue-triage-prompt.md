# Prompt — Issue Triage

```text
Use openwork-skill to triage this OpenWork issue: <issue URL or summary>.

Return:
1. Likely component and source paths.
2. User impact.
3. Reproduction plan.
4. Risk area: UI, desktop, server, OpenCode compatibility, cloud/Den, skills/MCP, packaging, docs.
5. Minimal fix strategy.
6. Tests/proof to include in a PR.
7. Questions to ask maintainers before implementation.

Distinguish what is inferred from what is verified.
```
